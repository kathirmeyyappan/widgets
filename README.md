# widgets

Hosting various widgets (mostly for the purpose of embedding in other pages) @ `kathirm.com/widgets/[something]`.

| Widget | Path | Description |
|--------|------|-------------|
| Spotify | [kathirm.com/widgets/spotify](https://kathirm.com/widgets/spotify) | Now-playing card backed by a Cloudflare Worker |
| Anime Activity | [kathirm.com/widgets/anime-activity](https://kathirm.com/widgets/anime-activity) | Recent (10 days) anime/manga updates via the MAL API |
| Stocks | [kathirm.com/widgets/stocks](https://kathirm.com/widgets/stocks) | Scrolling ticker bar + focused stock chart via Yahoo Finance (`?ticker=AAPL`) |
